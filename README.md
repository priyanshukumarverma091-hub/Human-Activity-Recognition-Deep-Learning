#  Human Activity Recognition using Deep Learning

## Overview
This project implements a Human Activity Recognition (HAR) system using the UCI HAR Dataset and a Deep Neural Network built with TensorFlow/Keras. The model classifies human activities based on smartphone accelerometer and gyroscope sensor data.

---

##  Dataset
- **Dataset:** UCI Human Activity Recognition Using Smartphones
- **Activities:**
  - Walking
  - Walking Upstairs
  - Walking Downstairs
  - Sitting
  - Standing
  - Laying

---

# Human-Activity-Recognition-Deep-Learning
A Deep Learning-based Human Activity Recognition (HAR) project using the UCI HAR Dataset. This project preprocesses smartphone sensor data, trains a neural network with TensorFlow/Keras, and evaluates performance using accuracy, precision, recall, F1-score, ROC-AUC, confusion matrix, and classification report.
